# Product

## What RepoMind is

An AI codebase intelligence and developer onboarding platform: connect a
GitHub repository, and get grounded answers, onboarding documentation, and
architecture visualization generated from the actual code — not generic
AI chat.

## MVP scope (Phase 1)

**Repo ingestion + AI chat Q&A** is the first vertical slice: connect a repo,
index it, ask questions, get answers grounded in the real codebase. This is
the core retrieval loop every later feature (onboarding guides, architecture
diagrams) builds on.

## Deferred to later phases

- Automated onboarding guide generation
- Interactive architecture/dependency visualization
- Team/workspace collaboration features

This file will grow into a fuller product spec as each phase is scoped.
